# 카카오 로그인 작업 기록 (이전 Supabase 방식)

상태: 구현 완료된 과거 작업 기록. 손 대표님이 MongoDB로 전환하기로 했으므로, 이 문서는 앞으로의 구현 지침으로 사용하지 않습니다.

## 당시 목표

Supabase Auth로 카카오 로그인을 연결하고, 안전한 쿠키 세션과 PKCE 콜백을 사용하려 했습니다. 로그인 성공·로그아웃 뒤에는 홈으로 돌아오고 로그인 상태만 표시하도록 했습니다.

## 당시 구현 내용

- Supabase 브라우저·서버 클라이언트와 Next.js 세션 갱신 처리
- OAuth 콜백에서 로그인 코드를 세션으로 교환
- 외부 사이트로 이동하는 위험한 콜백 주소 거부
- 로그인과 로그아웃 버튼, 설정 누락 안내, 오류 화면
- 로그인하지 않아도 무작위 번호 미리보기 사용 가능
- 프로필 정보는 앱 화면에 표시하거나 사용하지 않음

## 당시 보안·범위 규칙

- 카카오 로그인만 제공하며 이메일·비밀번호 로그인은 추가하지 않음
- 세션을 검증한 뒤 로그인 상태를 표시
- Kakao Client Secret은 브라우저 코드에 넣지 않음
- 계정 데이터 표와 권한 정책은 실제 계정 기능을 만들 때 추가

## 당시 확인 결과

포맷, 린트, 테스트 24개, 타입 검사, 프로덕션 빌드가 통과했습니다. 실제 카카오 로그인의 연결 확인은 Supabase와 Kakao 개발자 설정이 없어 하지 못했습니다.

## 현재 참고 사항

현재 앱 코드에는 이 Supabase 방식이 남아 있습니다. 손 대표님은 카카오 토큰 확인 후 MongoDB에 자체 세션을 저장하는 방식으로 정했습니다. 이 문서는 이전 Supabase 구현의 기록일 뿐이며, 새 방식은 별도의 승인된 계획으로 구현해야 합니다. Auth.js 방식은 선택하지 않았습니다.
