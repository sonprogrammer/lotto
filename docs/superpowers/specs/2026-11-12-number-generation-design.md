# 이슈 #6 번호 조합 생성 설계 초안

상태: 손 대표님 승인. 생성 요청마다 조합 전체에 대한 AI 설명 1~2줄을 포함한다.

## 목적과 범위

로그인 사용자가 과거 당첨 통계를 참고해 한 번에 1~10개 조합을 만든다. 기본값은 5개다. 자동 생성, 선택 번호 포함, 선택 번호와 AI 추천의 세 방법을 제공한다. 생성 결과에는 기준 회차·분석 기간·적용 조건과 통계 요약을 보여준다. 당첨 예측이나 확률 상승으로 표현하지 않는다.

## 검토한 방식

1. **AI가 번호를 직접 선택:** 자유로운 프롬프트를 다루기 쉽지만 같은 입력의 재현과 제약 검증이 어렵다.
2. **서버가 번호를 계산하고 AI가 조건을 해석·설명:** 숫자 범위·중복·고정 번호를 검증하고 계산 과정을 재현할 수 있다. 손 대표님이 선택한 방식이다.
3. **AI 없이 통계만 사용:** 무료 운영이 쉽지만 요청한 AI 분석 결과를 제공하지 못한다.

AI 제공사는 Groq으로 선택했다. 초기 모델 제안은 현재 제공 중인 `openai/gpt-oss-120b`다. 모델 제공 여부와 계정의 무료 한도는 배포 전에 확인한다.

## 입력과 생성 규칙 제안

- 번호는 1~45의 서로 다른 정수다. 고정 번호는 반드시 결과에 포함한다.
- 자동 생성에는 고정 번호를 넣지 않는다. 선택 번호 포함과 AI 추천에는 1~5개를 고정할 수 있다. 6개를 모두 정한 경우에는 그 한 조합만 결과로 보여주고 생성 개수는 1개로 제한한다.
- 사용자 프롬프트를 고르면 생성 방식과 관계없이 허용된 조건으로 해석해 반영한다. 프롬프트가 없으면 자동·선택 번호 방식에는 기본 통계 규칙을 적용하고, AI 추천 방식에는 기본 AI 해석 조건을 적용한다.
- 한 번의 결과에 같은 조합을 중복 표시하지 않는다. 조건을 동시에 만족하는 조합을 만들 수 없으면 조건을 완화하지 않고 이유를 알린다.
- 기본 분석 기간은 현재 분석 화면과 같은 최근 30회다. 결과에는 실제 반영된 회차 범위를 표시한다.
- 기본 규칙은 최근 30회의 번호별 출현, 홀짝·저고·구간·연속수 분포를 참고해 후보를 평가한다. 미출현 간격은 설명에 표시하되 오래 안 나온 번호를 당첨 가능성이 높은 번호로 취급하지 않는다.
- 다시 생성할 때는 새로운 후보 조합을 만든다. 통계 점수 계산은 같은 입력에서 동일하고, 요청별 생성 시드와 기준 회차를 결과에 기록해 재현할 수 있게 한다.

## AI와 데이터 전송 제안

- 서버가 Groq에 한 번 요청해 선택한 프롬프트를 허용된 조건으로 해석한다. 프롬프트를 선택하지 않으면 기본 규칙을 적용한다.
- 전송 데이터는 선택 번호, 프롬프트 본문, 필요한 집계 통계로 제한한다. 닉네임·이메일·계정 ID·개별 저장 조합·원본 전체 회차는 보내지 않는다.
- AI가 반환한 조건은 서버에서 허용 범위와 고정 번호 충돌 여부를 다시 검증한다. 해석하지 못한 문장은 적용하지 않았다고 결과에 표시한다.
- API 키는 서버 환경 변수 `GROQ_API_KEY`로만 받는다. AI 응답 실패나 무료 한도 초과 시 임의의 AI 분석을 꾸며 보여주지 않고 오류와 재시도를 안내한다.
- 모델 호출은 생성 요청당 최대 1회, 프롬프트는 최대 500자로 제한한다. 무료 한도에 맞춘 사용자별 요청 제한 수치는 계정 한도를 확인한 뒤 정한다.

## 화면과 저장 범위

- 생성 화면에서 방법, 고정 번호, 생성 개수, 분석 기간, 프롬프트를 선택한다. 실행 중에는 중복 요청을 막고 로딩 상태를 표시한다.
- 결과에는 조합별 번호와 공통 분석 요약, 실제 적용 조건, 적용하지 못한 프롬프트 조건을 보여준다. 추천 요청 한 번당 조합 전체를 설명하는 AI 문장 1~2줄을 표시하며 조합별 설명은 만들지 않는다.
- 프롬프트의 저장·관리 기능은 이슈 #7, 생성 조합의 계정 저장은 이슈 #8에서 연결한다. 이슈 #6은 선택 가능한 프롬프트가 없어도 기본 설정으로 동작하도록 한다.

## 확정된 결정과 남은 운영 설정

고정 번호 6개일 때 1개 결과만 허용하는 규칙, 다시 생성하면 새 조합을 만드는 규칙, 최근 30회 기본 기간, Groq 전송 범위와 무료 한도 초과 시 오류 처리, 요청당 AI 설명 1~2줄을 승인했다. 사용자별 일일 요청 제한 수치는 Groq 계정 한도 확인 후 운영 설정으로 정한다.
